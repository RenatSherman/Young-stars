# АК БАРС — Система развития

Веб-приложение для тренера по хоккею: карточки игроков, план/факт,
календарь тренировок, отчёты, экспорт в PDF и Excel.

## Возможности

- Учёт игроков с паспортом и фото
- Оценка навыков по разделам: техника, физика, тактика, психология
- Профиль навыков (лепестковая диаграмма) и динамика «начало → конец сезона»
- План/факт по неделям с формами работы и статусами выполнения
- Календарь тренировок Пн–Вс с возможностью группового назначения
- Справочник упражнений (блоки + видео)
- Отчёт по итогу месяца с процентом выполнения
- Экспорт в PDF (полный и краткий), Excel, JSON
- Синхронизация с облаком Supabase

## Технологии

- Vanilla JavaScript (ES-модули через обычные `<script>`)
- Chart.js — графики
- XLSX — работа с Excel
- jsPDF + html2canvas — экспорт в PDF
- Supabase — авторизация и хранение данных
- GitHub Pages — хостинг

## Локальный запуск

Открыть `index.html` через Live Server (расширение VS Code) или через
`python -m http.server 8000`.

## Публикация

Сайт автоматически публикуется на GitHub Pages из ветки `main`.
